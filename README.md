# CampusSpace AI

AI-powered campus room finder that helps students and staff quickly discover available classrooms, study rooms and meeting spaces.

**Live demo:** https://campus-space-ai-room-finder--navadeepnomula7.replit.app/

---

## Overview

Finding a free room on campus often means walking around or checking several schedules. CampusSpace AI brings this into one simple web app: search for a space, see what fits your needs, and get smart, AI-assisted suggestions.

## Features

- Search for classrooms, study rooms and meeting spaces
- AI-assisted room recommendations based on what you need
- Clean, mobile-friendly interface
- Fast, responsive experience

## Getting Started

### Prerequisites

- Node.js 18 or higher
- npm (comes with Node.js)

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
cd YOUR-REPO

# Install dependencies
npm install
```

### Environment Variables

Create a `.env` file in the project root (never commit this file):

```env
AI_API_KEY=your_api_key_here
PORT=3000
```

### Run the App

```bash
npm run dev
```

Then open `http://localhost:3000` in your browser.

## Usage

1. Open the app.
2. Enter what you are looking for (for example, a quiet study room for 4 people).
3. Browse the results and AI suggestions.
4. Pick the room that fits best.
